# 🐍 Python Nested Loops

A beginner-friendly Python project that demonstrates how **nested loops** work in Python. This project includes simple examples of nested `for` loops and a practical program that generates a rectangle using a user-defined symbol.

---

## 📖 Overview

This project helps beginners understand the concept of **nested loops**, where one loop runs inside another. It also shows how nested loops can be used to create patterns and solve real programming problems.

---

## ✨ Features

- 🔁 Demonstrates nested `for` loops
- 🔢 Prints number sequences using loops
- 🟦 Generates a rectangle with any symbol
- ⌨️ Accepts user input for rows, columns, and symbol
- 📚 Beginner-friendly and easy to understand
